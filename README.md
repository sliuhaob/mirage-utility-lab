# Mirage Utility Lab

Public website assets for the CS2 Mirage, Nuke, Ancient and Dust II utility maps.

Website: https://cs2.roxy-design.com

Hosted on GitHub Pages. The site runs entirely in the browser and includes its
map model, Three.js modules and Draco decoder. No local server is required.

Original game assets belong to Valve. This is an unofficial educational tool.
Third-party licenses are in vendor/LICENSE and vendor/draco/LICENSE.
