# Mirage Utility Lab

Public website assets for the CS2 Mirage, Nuke, Ancient, Dust II, Inferno and Anubis utility maps.

Website: https://cs2.roxy-design.com

Hosted on GitHub Pages. The map viewer includes its models, Three.js modules
and Draco decoder. Developer accounts, tutorial data and uploaded videos are
served by the project's Cloudflare Worker, D1 database and private R2 bucket.
Visitors do not need access to the developer's computer.

Original game assets belong to Valve. This is an unofficial educational tool.
Third-party licenses are in vendor/LICENSE and vendor/draco/LICENSE.
